# Load testing — aiperf (in-cluster)

The standard load probe is generated by **[aiperf](https://github.com/ai-dynamo/aiperf)**
(NVIDIA ai-dynamo), an OpenAI-compatible benchmarking tool.

## How it runs

aiperf is distributed as a Python package, so the workflow runs
it as a **Kubernetes Job** on a Python base image (`AIPERF_IMAGE`, default `python:3.12-slim`) that
`pip install`s aiperf (`AIPERF_PIP_SPEC`, default `aiperf`) at start — see
[`../templates/aiperf-job.yaml.tmpl`](../templates/aiperf-job.yaml.tmpl). Running in-cluster means
the load hits the workspace `Service` directly over cluster DNS
(`http://<svc>.<ns>.svc:<port>`), exercising the real serving path with no `kubectl port-forward`.

The Job runs:

```bash
aiperf profile \
  --model "$MODEL_ID" --tokenizer "$MODEL_ID" \
  --url "http://<endpoint-svc>.<ns>.svc:<port>" \
  --endpoint-type chat --streaming \
  --concurrency $LOAD_CONCURRENCY --request-count $LOAD_N_PROMPTS \
  --synthetic-input-tokens-mean $LOAD_INPUT_TOKENS --output-tokens-mean $LOAD_OUTPUT_TOKENS \
  --artifact-dir /tmp/aiperf
```

It then base64-encodes `profile_export_aiperf.json` between marker lines in the pod log; the
execute phase ([`../bin/40-execute.sh`](../bin/40-execute.sh)) extracts it to
`runs/<scenario>/<ts>/results/aiperf.json`. The functional probe is a separate one-shot in-cluster
`curl` pod that verifies a non-empty completion.

## Configuration

Parameters live in [`../config/common.env`](../config/common.env): `AIPERF_IMAGE`, `LOAD_N_PROMPTS`,
`LOAD_CONCURRENCY`, `LOAD_INPUT_TOKENS`, `LOAD_OUTPUT_TOKENS`.

## Notes

- The run report reads throughput/TTFT/latency from aiperf's `profile_export_aiperf.json` (each
  metric is an object with `unit`/`avg`/`p50`/`p90`/…; latencies are in milliseconds).
- The in-cluster `pip install aiperf` runs at Job start; for faster cold starts a small prebuilt
  aiperf image can be substituted via `AIPERF_IMAGE`.
- aiperf reaches Hugging Face for the tokenizer from inside the cluster (the `HF_TOKEN` secret is
  injected into the Job).
